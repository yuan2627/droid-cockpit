# Changelog

## 1.0.0 - 2026-07-01

Initial public release preparation.

- Added the Chinese-first Droid Cockpit desktop UI for Factory Droid CLI configuration.
- Added model, MCP, skill, Droid, prompt, session, usage, backup, and slash command management pages.
- Added AI-generated section icons and screenshot documentation.
- Added strict settings preservation for current Factory Droid configuration fields.
- Added safer BYOK model writing that keeps Cockpit-only metadata out of `settings.json`.
- Added single-instance behavior, no-console Windows helper processes, transactional config restore, and stricter model endpoint tests.
- Added repository hygiene files for security reporting, third-party notices, version checks, and CI.
